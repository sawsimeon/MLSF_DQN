# De novo molecular generation using MLSF (EGFR)

The process of developing potent and selective inhibitors involves a complex interactive procedure of structure based design. Structure based design (SBD) involves a structurallly driven, iterative iteration to a molecule to increase its potency by tuning the fine balance between attractive adn repulsive interaction. An ability to effectively understand and predict these subtleties is one of the challenges in SBD. It will allow the 3D crystallographic coordinates to be used in more quantitative fashion to guid the strucural modification of a lead series. 

Pattern recognition, natural language processing, biomedicine and cheminformatics have all benefited greatly from recent development in machine learning. Likewise, de novo structure generation has been adapted as a data-driven strategy for haversting novel molecules are new chemical. Briefly, computational models have to (i) create molecules, (ii) predict potency and filter them in terms of physical properties and syntheticability and (iii) search for better molecules using the knwoledge gain from the previous steps. 

In here, we introduce a new deep genrative model for design of novel pyrimidine based scaffold for EGFR inhibitors by combinbin deep reinforcement learning and machine learning scoring function. The local models were created using PLEC features from dock poses of pyrimidine series against a given receptor and learn from corresponding EGFR affinity. The model changes the chemical structure of the intput compound directly and automatically in order to improve the affinity against the target protein. We have utilized our model to design novel pyrimidine based on literature as a starting structure. 

In the deep generative model, the input molecule is optimized in a step-wise manner in which atoms are added, bonds are added and bonds are removed. The structure modification is entirely based on the input molecule. The process of molecular modification can be viewed as Markov decision process. The agent can interact with a incomplete representation of the environment to generate a desirable SMILES as a complte sequence. The agent is the Deep Q-Learning Network in which the next modification of molecules is predicted based on the current state of a molecules and action to get maximum reward (Q-value) using the desirable property.
